# Tech With Prosper

My developer portfolio, live at **https://tech-with-prosper.vercel.app**.

Built with Next.js, TypeScript and Tailwind CSS, and deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All the site's text (profile, skills, experience, projects) lives in `content/data.ts`. Pushing to `main` deploys the site automatically.
